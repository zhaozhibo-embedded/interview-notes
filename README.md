# 嵌入式面试笔记 · interview-notes

我是赵智博，2026 届嵌入式软件工程师，目前在深圳做 TWS 蓝牙音频固件。
这个仓库记录我的 C / RTOS 学习笔记和真实项目调试过程。

**不抄八股。每篇只回答三个问题：结论是什么、为什么是这样、我怎么验证的。**

## 为什么有这个仓库
