# 环形缓冲区

## 设计要点（面试要能主动讲出来）

1. **容量取 2 的幂，用 `& (size-1)` 代替 `% size`**，省掉一次除法（Cortex-M0 没有硬件除法）。
2. **`head - tail` 无符号回绕仍然正确**，所以不需要额外的计数变量。
3. **判满用"留一格"还是"满=size"？** 这里用后者：`used == size` 即满，代价是 `head`/`tail` 必须区分类型（`uint32_t`），但能 100% 用满容量。
4. **SPSC 无锁**：`head` 只有生产者写，`tail` 只有消费者写，天然无竞态；跨核时需要内存屏障。
5. **`volatile`** 用在 `head`/`tail`，防止编译器把索引缓存在寄存器里。

## 边界情况（测试覆盖）

- `size` 非 2 的幂 → 拒绝初始化
- 空读 / 满写 → 返回失败，不破坏数据
- 写满后继续写 → 拒绝，不覆盖未读数据
- 回绕：连续读写多轮，索引跨过缓冲区末尾
- 批量读写：长度超容量时截断，回绕段用两次 `memcpy`
