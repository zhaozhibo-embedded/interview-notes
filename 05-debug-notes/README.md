# 调试记录

> 这个目录是整个仓库最值钱的部分。
>
> 每篇记录一次真实的定位过程：现象 → 假设 → 验证 → 根因 → 修复 → 回归。
> **面试官看这一篇，比看十篇八股更能判断你的水平。**

## 写作要求

1. **先列假设，再写验证**，不要写成"最后发现是 XX"的事后总结。
2. **每个假设都要写"我用什么手段排除的"**：示波器哪一通道、抓的什么波形、日志哪一行、二分到哪个版本。
3. **写清失败路径**：哪些假设是错的、错在哪，这比正确答案更显功力。
4. **脱敏**：不出现公司名、客户名、完整型号+项目名组合、SDK 源码。
